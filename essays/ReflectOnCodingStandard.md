## My first time with coding standards

I always thought coding standards are important for everyone and is a vital part to programming. Coding standards can make code easier to read and understand, especially when multiple people are working on the same project. I also agree that coding standards can help you learn a programming language because they make you pay more attention to how you write your code instead of just making sure it works. With coding standards everyone can be on the same page making progression be more quickly and efficient.

## My opinion on coding standards in software engineeringWhy are smart questions important?

I think coding standards are one of the better ways to improve the quality of software. Having everyone follow similar rules makes it easier to understand someone else's code and find problems. ESLint is helpful because it can automatically find mistakes or parts of your code that do not follow the standards. Sometimes this can feel unnecessary when your code works but ESLint still gives you an error. However, I think it is better to find these problems while you are coding rather than later when the project becomes bigger. It can also teach you better habits over time.

## My experience with ESLint

After my first week of using ESLint with VSCode, I would say my experience has been both useful and frustrating. Fixing small errors can be annoying, especially when the code already works. At the same time, ESLint has made me more aware of how I write my code. Instead of only thinking about whether my program works, I also think about whether it is organized and follows good practices. Overall, I think coding standards can be frustrating at first, but they are useful for becoming a better programmer. I now understand why having consistent standards can make software easier to read, maintain, and work on with other people.
